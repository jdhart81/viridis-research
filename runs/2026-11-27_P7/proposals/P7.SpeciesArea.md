# Rationale: `P7.SpeciesArea`

## What the statement means

Under a power-law species–area relationship `S = k·A^z` (Arrhenius 1921), keeping a fraction `a`
of an area `A` keeps the fraction `S(a·A)/S(A) = k·(aA)^z / (k·A^z) = a^z` of the species.
**The constant `k` (and the total area `A`) cancels in every part**, so the module is stated
directly in terms of fractions. Keeping a fraction `s` of the species needs the area fraction
`s^(1/z)`. Powers are real powers (`Real.rpow`).

`Statement` is a conjunction of four parts, each for all real `z` with `0 < z ≤ 1`:

1. **Retained fraction bound.** For `0 ≤ a ≤ 1`: `a ≤ a^z` and `a^z ≤ 1`. Losing area never loses
   a larger fraction of species than of area.
2. **Strict gain.** If `z < 1`, for `0 < a < 1`: `a < a^z`.
3. **Monotone.** For `0 ≤ a ≤ b`: `a^z ≤ b^z`. More area kept never keeps fewer species.
4. **Area needed.** For `0 ≤ s ≤ 1`: `(s^(1/z))^z = s` and `s^(1/z) ≤ s`. The area fraction
   `s^(1/z)` keeps exactly the species fraction `s` and is never more than `s`.

**`S = k·A^z` is assumed.** It is an empirical regularity, not a law. The mathematics in the
module is about `a ^ z` for real numbers, and the species interpretation exists only through
this assumption.

## Hypotheses, listed

- `0 < z` (all parts). With `z = 0`, part 4's `1/z` is `0` in Lean and `(s^0)^0 = 1 ≠ s`.
- `z ≤ 1` (all parts). Needed for part 1 and part 4's inequality; see the negative control.
  Part 3 holds for any `z ≥ 0`; the bound is kept for uniformity of the conjunction.
- `z < 1` (part 2 only), for strictness.
- `0 ≤ a ≤ 1` (part 1), `0 < a < 1` (part 2), `0 ≤ a ≤ b` (part 3), `0 ≤ s ≤ 1` (part 4). The
  nonnegativity hypotheses matter because `Real.rpow` of a negative base is defined through the
  complex logarithm and has no species meaning.

## Hand check of the notes

- Part 1: for `0 < a ≤ 1`, `x ↦ a^x` is antitone, so `z ≤ 1` gives `a = a^1 ≤ a^z`. At `a = 0`,
  `0^z = 0` for `z > 0`, so `0 ≤ 0`. `a^z ≤ 1` since `a ≤ 1` and `z ≥ 0`. Correct.
- Part 2: for `0 < a < 1`, `x ↦ a^x` is strictly antitone, so `z < 1` gives `a^1 < a^z`. Correct.
- Part 3: `Real.rpow_le_rpow` with `0 ≤ a ≤ b`, `0 ≤ z`. Correct.
- Part 4: `(s^(1/z))^z = s^((1/z)·z) = s^1 = s` by `Real.rpow_mul` (needs `0 ≤ s`) and `z ≠ 0`.
  `1/z ≥ 1` since `0 < z ≤ 1`, so `s^(1/z) ≤ s^1 = s` for `0 ≤ s ≤ 1`. Correct.

Before drafting, we wrote a private Lean proof of the exact `Statement` text in a scratch file
outside `out/` to make sure the proposal is not false. We make no proof claim here: the proof is
task P7-T003. For the edge case `0 ≤ a` with `a = 0` it used `Real.rpow_le_rpow_of_exponent_ge'`
rather than `Real.rpow_le_rpow_of_exponent_ge`, because in the pinned Mathlib the unprimed lemma
needs `0 < x`. `norm_num`, `simp`, `aesop`, `decide`, `grind`, `positivity` and `linarith` (after
`unfold Statement`) each fail to close the statement.

## Sanity checks in the module (all checked by `norm_num` after rewriting)

`decide` cannot evaluate real powers, so these checks use `norm_num`, `Real.rpow_mul` and
`Real.rpow_natCast`.

- Witness: `z = 1/2, a = 1/4` gives `a^z = 1/2`. Keeping a quarter of the area keeps half the
  species.
- Witness: `z = 1/2, s = 1/2` gives area fraction `s^(1/z) = 1/4`.
- **Negative control (part 1):** the bound fails for `z > 1`. With `z = 2, a = 1/2`,
  `a^z = 1/4 < 1/2 = a`. The module checks `(1/2 : ℝ) ^ (2 : ℝ) < 1/2`.

## Why this is the right target

These four facts are what a planner uses from the power law: a floor on species kept for a given
area kept, strictness when `z < 1`, monotonicity, and the inverse (area needed for a target).
Stating them for fractions makes `k` drop out and keeps the statement pure real analysis about
`Real.rpow`.

## Relation to the ladder

P7-T003 proves this statement. It is independent of `P7.HabitatThreshold`. Together they give the
"threshold" and "bound" halves of the habitat-loss kernel described in the P7 README.

## What the statement does not settle

- Whether any real biota follows `S = k·A^z`, or any value of `z` (published values vary widely
  by taxon, region and scale).
- **Extinction debt:** the power law gives an eventual equilibrium count, not when species are
  lost.
- **Which species are lost:** it counts species and ignores identity, endemism and function.
- Where the remaining habitat lies (fragmentation, configuration, connectivity).
- Whether the species–area curve for a whole region applies to habitat lost within it (the
  difference between species–area and endemics–area relationships).
