# Rationale: P3.RecoveryWorkFloor

## What the statement says
This extends `target_requires_supply` of the Useful and Dissipated Work Ledger (canon Run-163,
`context/UsefulDissipatedWork.lean`, doi:10.5281/zenodo.22736716). The two supplies are read as
a fresh supply `wf` and a recovered supply `wr`, with modeled efficiencies `ef, er ∈ [0, emax]`.
Useful work is `useful wf wr ef er = ef·wf + er·wr`, which is the Run-163 `useful w1 w2 e1 e2`
with `w1 = wf`, `w2 = wr`, restated here over Mathlib only. With
`freshFloor T wr emax = (T - emax·wr)/emax`, `Statement` asserts:

1. floor: if `T ≤ useful wf wr ef er` then `freshFloor T wr emax ≤ wf`;
2. attainment: if `emax > 0`, `wr ≥ 0` and `emax·wr ≤ T`, then `freshFloor T wr emax ≥ 0` and
   `useful (freshFloor T wr emax) wr emax emax = T`. The floor is reached with equality at
   efficiencies `ef = er = emax`, which are admissible, so it cannot be raised.

## Hypotheses, all listed
- Part 1: `0 ≤ wf`, `0 ≤ wr`, `0 ≤ ef ≤ emax`, `0 ≤ er ≤ emax`, `0 < emax`, `T ≤ useful …`.
- Part 2: `0 < emax`, `0 ≤ wr`, `emax·wr ≤ T`.
- No assumption `emax ≤ 1`, as in Run-163. The statement is about a cap on modeled efficiency.

## Relation to the canon
Since `(T - emax·wr)/emax = T/emax - wr`, part 1 is algebraically equivalent to Run-163's
`T/emax ≤ w1 + w2` in this setting. It therefore extends the canon only mildly. What it adds is
the recovery reading (each unit of recovered supply at the cap offsets one unit of fresh
supply), together with the attainment half. Run-163 has no attainment theorem, only a numeric
witness. This proposal is deliberately conservative so that the recovery kernel can cite one
sealed, two-sided statement.

## Controls (examples, `norm_num`)
- Run-163 witness `(8, 4, 3/4, 1/2)`: useful work `8`, and the floor `20/3 ≤ 8` at `emax = 3/4`.
- Attainment: `emax = 1/2`, `wr = 4`, `T = 8` give floor `12`, and `useful 12 4 (1/2) (1/2) = 8`.
- Recovery lowers the floor: `12 < 16 = freshFloor 8 0 (1/2)`.
- Negative control: `wf = 11 < 12` gives `useful = 15/2 < 8` at the cap.
- Negative control: efficiency `1 > emax = 1/2` reaches `T = 8` with `wf = 4 < 12`, so the cap
  hypothesis is necessary.
- Negative control: `emax·wr > T` makes the floor negative, so part 2 needs `emax·wr ≤ T`.

## What the statement does not settle
This is a bound on modeled efficiency. It is not a Landauer bound and does not rely on the
Intelligence Bound, which remains a conjecture. It makes no claim about any real efficiency,
any real recovered supply, or the work cost of recovering material in the first place. The
recovered supply `wr` is taken as given.
