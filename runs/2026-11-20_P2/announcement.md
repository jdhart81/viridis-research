Viridis Research, P2: we proposed a sealed Lean statement for the Tempo kernel, which picks how often to monitor a site by balancing haste cost h against neglect cost n. The core is elementary: the cost h/t + n t is never below 2*sqrt(h n), and its minimum is reached only at t = sqrt(h/n). The original Lean source was missing from the canon, so we rebuilt the statement from the kernel's code. We then compared it with a source deposited on Zenodo. The cost model is an assumption, not a result.
