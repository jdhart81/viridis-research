## What the statement means

All quantities are extended nonnegative reals. For a measure `μ` on `Ω`, a hidden process `X`,
an observation process `O` (both `Ω → ℝ≥0 → State`) and a horizon `τ`:

- `I_t(τ) = I(X_{[0,t+τ]}; O_{[0,t]})`, where `I(U; V) = KL(P_{U,V} ‖ P_U ⊗ P_V)` is Mathlib's
  `klDiv`;
- the rate is `İ(τ) = limsup_{t→∞} I_t(τ) / t`;
- the bandwidth is `B = limsup H(O_{[0,t]}) / t`, with `H(V) = I(V; V)`;
- the richness is `ρ(τ) = limsup I_t(τ) / H(O_{[0,t]})`;
- `SatisfiesLandauerLimit μ X O τ P T kB` is `P ≥ İ(τ) · ofReal(kB · T · ln 2)`.

`Statement := CoreBound ∧ ThermodynamicBound ∧ LandauerDissipationBound ∧ DataBound`:

1. **`CoreBound`** (`intelligence_bound`). If `μ` is a probability measure, `kB > 0`, `T > 0`,
   **`SatisfiesLandauerLimit μ X O τ P T kB`** holds, `B ≠ ⊤` and `ρ ≤ 1`, then
   `İ ≤ min (ρ · B) (ofReal (P / (kB T ln 2)))`.
2. **`ThermodynamicBound`** (`thermodynamic_bound_lemma`). If `kB > 0`, `T > 0` and
   **`SatisfiesLandauerLimit`** holds, then `İ ≤ ofReal (P / (kB T ln 2))`. No probability
   assumption is needed.
3. **`LandauerDissipationBound`** (`landauer_dissipation_bound`). For any `erasureRate`, if
   **`P ≥ erasureRate · kB T ln 2`** and `erasureRate ≥ İ`, then `P ≥ İ · kB T ln 2`.
4. **`DataBound`** (`data_bound_lemma_conditional`). If `μ` is a probability measure,
   `B ≠ ⊤` and `ρ ≠ ⊤`, then `İ ≤ ρ · B`.

## The Landauer limit is a hypothesis, not a result

**Nothing in this statement proves the Landauer limit for any physical system.**
`SatisfiesLandauerLimit` is a hypothesis of parts 1 and 2. It is named in the module docstring
and in the docstring of the definition. Part 3 also takes its Landauer floor
`P ≥ erasureRate · kB T ln 2` as a hypothesis. That floor is about erasure, in line with the
canon's v8 framing correction: `k_B T ln 2` bounds the cost of erasing or maintaining
information, not of acquiring it. A proof of the Statement would establish only this: *if* a
process pair obeys the Landauer inequality, *then* its rate is below the stated ceilings. Whether a
given decision process obeys it is a physical question outside the statement. The kernel's use of
the thermodynamic ceiling stays ASSUMED until that question is addressed separately.

This matters because of P5. An early source stated the bound with the rate quantified over all
reals and no hypothesis tying it to any system. The sealed `P5.UnrestrictedBoundFalse` shows
that version is false: rate `1`, power `0`, `D = 0`. The last negative control in this module
repeats the point in the present setting. Without the hypothesis, `∀ rate, rate ≤ P/(kB T ln 2)`
fails at `P = 0`. (The brief points to `projects/P5/README.md`. That file is not in this session's
inputs, so I used the sealed P5 statements as the record.)

## Kernel decision it backs

The brief describes this as the conditional bound the audit kernel applies. The kernel compares
a decision process's information rate with `min(ρ B, P / (kB T ln 2))`. The data branch
(part 4) is a mathematical fact about the defined limsups, given finite `B` and `ρ`. The
thermodynamic branch (part 2), and therefore the core (part 1), applies only to processes for
which the Landauer hypothesis is granted. Any audit decision that uses the thermodynamic ceiling
inherits that hypothesis. I do not have the kernel's registry entry or code, so this description
of the decision rests on the brief and the canon docstrings.

## Which parts are elementary

- **Part 2 is elementary.** The hypothesis is `P ≥ İ · K` with `0 < K < ∞`. The conclusion
  `İ ≤ P / K` is the same inequality rearranged. A short case split is needed for `İ = ⊤`, which
  the hypothesis excludes because `⊤ · K = ⊤ > P`.
- **Part 3 is elementary**: `İ · K ≤ erasureRate · K ≤ P`, one monotonicity step and
  transitivity. It is the same as the canon's `learning_dissipation_link`.
- **Part 1 is elementary given parts 2 and 4**: `le_min` of the two.
- **Part 4 is the only part with content.** It uses three facts. (a) If `B ≠ ⊤`, then eventually
  `H(O_{[0,t]}) ≠ ⊤`. (b) `H(Y) = 0 ⇒ I(X; Y) = 0`. This needs Gibbs' inequality through
  `klDiv_eq_zero_iff`, and the fact that a self-independent variable is independent of everything.
  (c) `limsup (u · v) ≤ limsup u · limsup v` in `ℝ≥0∞`, under finiteness side conditions
  (`ENNReal.limsup_mul_le'`). It is still standard and short, but it is not pure algebra.

## Observations on the definitions (no change made)

- **Units.** Mathlib's `klDiv` uses the natural logarithm, so `İ`, `B` and `H` are in nats per
  unit time. The factor `kB T ln 2` is the Landauer energy per **bit**. Per nat it is `kB T`.
  The predicate `P ≥ İ_nat · kB T ln 2` is therefore weaker by a factor `ln 2 ≈ 0.69` than the
  per-nat Landauer inequality `P ≥ İ_nat · kB T`. As a hypothesis it remains a valid conditional,
  but the number `P / (kB T ln 2)` is a ceiling in nats per unit time computed with a per-bit
  energy. Kernel documentation that reports the ceiling "in bits" should either convert or say
  this.
- **Entropy as self-information.** `H(V) := KL(P_{V,V} ‖ P_V ⊗ P_V)` agrees with Shannon
  entropy (in nats) for discrete laws. Mathlib sets `klDiv μ ν = ⊤` when `μ` is not absolutely
  continuous with respect to `ν`. For a real-valued variable with an atomless law, the joint law
  sits on the diagonal, which has product measure zero, so `H = ⊤`. I did not work out when `H`
  is finite for path-valued observations on `[0, t]` with the product σ-algebra. The hypothesis
  `B ≠ ⊤` in parts 1 and 4 excludes every case where entropies are eventually infinite. The data
  branch therefore has content only for observation processes whose path laws have finite
  self-information.
- **Division by `t`.** At `t = 0`, `I / 0 = ⊤` in `ℝ≥0∞`, unless `I = 0`. This does not affect
  `limsup` along `atTop`.

## Controls (examples in the module)

Witnesses:
- A one-point sample space under the Dirac measure has `I(X; Y) = 0` for any `X, Y`. The proof is
  `map_dirac`, `dirac_prod_dirac` and `klDiv_self`.
- For the constant process on `Unit` with values in `ℕ`, `İ = 0`, and `SatisfiesLandauerLimit`
  holds at `P = 0`, `T = kB = 1`. So the Landauer hypothesis is satisfiable and the core's
  hypotheses are not contradictory.
- The thermodynamic ceiling `ofReal(1 / (1 · 1 · ln 2))` is positive.
- The arithmetic of the two ceilings in cleared form, checked by `decide` over `ℕ`:
  `min 3 3 = 3` and `min 3 1 = 1` (the power-limited case).

Negative controls:
- The hypothesis has content. At `P = 0`, `kB = T = 1`, `SatisfiesLandauerLimit` forces `İ = 0`.
- An infinite rate never satisfies the Landauer inequality at finite power.
- Without the hypothesis the bound is false: `¬ ∀ rate, rate ≤ ofReal(0 / (1 · 1 · ln 2))`
  (rate `1`). This is the P5 point.

## Relation to the ladder

This is the first P2 kernel whose sealed statement is measure-theoretic rather than finite
algebra. Within the Intelligence Bound family it sits between the false unrestricted postulate
