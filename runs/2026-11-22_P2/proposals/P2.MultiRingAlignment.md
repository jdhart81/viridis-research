## What the statement means

Per-ring data are finite real families on `Fin K`: an alignment factor `c k` (read as
`cos²Θ_k`), a dissipation fraction `D k`, together with power `P`, Boltzmann constant `kB` and
temperature `T`. The definitions are

    kappa kB T        = kB * T * log 2
    Dbar K D          = (∏ k, D k) ^ (1 / K)            (real power)
    alignFactor K c   = ∏ k, c k
    baseRate K P kB T D = P * Dbar K D / kappa kB T
    mrabBound K P kB T D c = baseRate K P kB T D * alignFactor K c

`Statement` is the conjunction of the four canon theorems, each with exactly its canon
hypotheses:

1. `Dbar_le_arith_mean`: for `0 < K` and `D k ≥ 0` for all `k`, `Dbar K D ≤ (∑ k, D k) / K`.
2. `mrab_bound_le_baseRate`: for `P ≥ 0`, `kB > 0`, `T > 0`, `D k ≥ 0`, `0 ≤ c k ≤ 1`,
   `mrabBound ≤ baseRate`.
3. `mrab_saturation`: if `c k = 1` for every `k`, `mrabBound = baseRate` (no other hypothesis).
4. `mrab_reduces_to_IB`: for `K = 1` and `c 0 = 1`, `mrabBound 1 P kB T D c = P * D 0 / kappa kB T`
   (no other hypothesis).

## Every hypothesis

| Part | Hypotheses | Role |
|---|---|---|
| 1 | `0 < K`; `∀ k, 0 ≤ D k` | Real AM–GM needs nonnegative entries and a nonempty index |
| 2 | `0 ≤ P`; `0 < kB`; `0 < T`; `∀ k, 0 ≤ D k`; `∀ k, 0 ≤ c k`; `∀ k, c k ≤ 1` | Base rate `≥ 0` and alignment product in `[0, 1]` |
| 3 | `∀ k, c k = 1` | Empty-product algebra |
| 4 | `c 0 = 1` | `Dbar 1 D = D 0 ^ 1` |

The canon module also states `alignFactor_nonneg`, `alignFactor_le_one`, `Dbar_nonneg`,
`Dbar_le_one`, `baseRate_nonneg` and `mrabBound_nonneg`. They are helper facts and the brief does
not list them, so they are left out. Parts 1 and 2 imply most of them for the inputs that matter.

## Kernel decision it backs

The kernel reports the MRAB ceiling `(P · D̄ / κ) · ∏ cos²Θ_k` for an agent working across `K`
rings. The four parts back four properties of the reported number. (2) It never exceeds the
unaligned base rate at the same rings. (3) It equals the base rate exactly when every ring is
perfectly aligned. (4) With one ring it is `P · D / κ`. (1) Replacing `D̄` by the arithmetic mean
of the `D k` is conservative, giving an upper estimate.

## Scope: facts about a defined bound

**These are facts about a defined number. They do not show that any layered system attains or
obeys the ceiling.** No information rate of any system appears in the statement. The physical
reading of `mrabBound` as a bound on `dI_joint/dt` (canon docstring, eq. (3) of Run-016) is an
assumption outside the statement. The `cos²Θ_k` reading of `c k` is a comment only: the
statement takes `c k` as an arbitrary real number in `[0, 1]` and does not relate it to any angle
or to the Fisher–Wasserstein geometry.

Part 4 says that MRAB reduces to the expression `P · D / κ`. It does **not** say that any rate is
bounded by that expression. The unrestricted claim "every rate is at most `P · D / (kB T ln 2)`"
is the postulate that the sealed `P5.UnrestrictedBoundFalse` shows false. The last negative
control in the module makes the same point for `mrabBound`.

## A docstring overreach (the statement is not changed)

The canon docstring of `mrab_bound_le_baseRate` says "adding rings can only shrink the joint
information-rate budget". The theorem does not say that. It compares `mrabBound K` with
`baseRate K` at the **same** `K` and the same `D`. Since `D̄` is a geometric mean, adding a ring
can raise it. A module example shows this: one ring with `D = 1/4` and ceiling `(1/4)/ln 2`; add a
perfectly aligned ring with `D = 1` and the ceiling becomes `(1/2)/ln 2`. The proposal restates
what the theorem proves. Any kernel text that claims monotonicity in `K` should be corrected.

## Elementary

**All four parts are elementary.**
- Part 1 is the weighted AM–GM inequality with equal weights (Mathlib
  `Real.geom_mean_le_arith_mean`).
- Part 2 is `x · a ≤ x` for `x ≥ 0` and `a ∈ [0, 1]`, using `Finset.prod_le_one` and `log 2 > 0`.
- Parts 3 and 4 are unfolding plus `∏ 1 = 1` and `x ^ (1:ℝ) = x`.

Sealing them is worth doing because it gives assurance under the pinned toolchain, not because
the mathematics is new.

## Lean conventions that matter

- With `kB = 0` or `T = 0`, `kappa = 0` and Lean's `x / 0 = 0` makes `baseRate = 0`. Parts 3
  and 4 still hold, and the canon states them without positivity hypotheses. The proposal keeps
  them that way.
- At `K = 0`, `Dbar 0 D = 1 ^ (1/0) = 1 ^ 0 = 1`. This is why part 1 needs `0 < K` (see
  controls).

## Faithfulness

The restatement is faithful: same definitions character for character (except for the
namespace), same hypotheses, same conclusions. The canon gives `K` in part 1 as `(K : ℝ)` through
the coercion in `/ K`, and so does the restatement. Nothing is weakened or strengthened.

## Controls (examples in the module)

`decide` is used where the check can be phrased over `ℕ`. `decide` over `ℚ` does not reduce
(rational normalisation uses well-founded recursion), so cleared-denominator forms are used.
Checks over `ℝ` use `norm_num` and short rewrites.

Witnesses:
- `kappa 1 1 = log 2 > 0`, `kappa 2 3 = 6 log 2`.
- `alignFactor 2 (1/2, 1/2) = 1/4`, and the same product in cleared form (`decide`).
- `Dbar 2 (1/4, 1) = 1/2`, which is below the arithmetic mean `5/8`. The cleared form `4² = 2·8`,
  `2·4 < 2+8` is checked by `decide`.
- `Dbar 1 (3/10) = 3/10`.
- `P = 4, kB = T = 1, D = (1,1), c = (1/2,1/2)`: `baseRate = 4/ln 2`,
  `mrabBound = 1/ln 2 < baseRate`.

Negative controls:
- `0 < K` is needed in part 1: `Dbar 0 _ = 1 > 0 = 0/0`.
- `D ≥ 0` is needed in part 1: `D = (−1, −1)` gives `Dbar = 1 > −1`.
- `c ≤ 1` is needed in part 2: `c = 2` on one ring gives ceiling `2/ln 2 > 1/ln 2`.
- Saturation needs `c = 1`: `c = 1/2` gives a ceiling different from the base rate.
- Not monotone in `K`: adding an aligned ring raises the ceiling from `(1/4)/ln 2` to
  `(1/2)/ln 2`.
- About a number, not a system: `¬ ∀ rate, rate ≤ mrabBound 1 0 1 1 (1) (1)`, since the ceiling
  is `0`.

`unfold Statement` I ran these one-shot tactics: `rfl`, `decide`, `simp`, `norm_num`, `aesop`,
`linarith`, `nlinarith`, `positivity`, `grind`, `tauto`, `omega`, `simp_all`, `trivial`,

four-way split followed by `simp_all [defs]`. None of them closes `Statement`; see the session
notes for the final probe log.

I also wrote a scratch derivation in `/tmp`, outside `out/`, porting the canon proofs to the
restated definitions. It compiles, which shows only that the target is not false under the
pinned Mathlib. **It is not a claim of proof**, and no proof is submitted.
