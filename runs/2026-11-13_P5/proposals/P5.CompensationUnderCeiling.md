# Rationale: `P5.CompensationUnderCeiling`

## What the statement says

With `cap P D C := P * D / C` (capacity at power `P`, diversity fraction `D`, per-bit cost `C`),
defined inside the statement's namespace, `Statement` is the conjunction of four parts:

1. **Interior compensation exists and is unique.** For `0 < C`, `0 < P`, `0 < dD < D`:
   `cap (P*D/(D - dD)) (D - dD) C = cap P D C`, and every `P'` with
   `cap P' (D - dD) C = cap P D C` equals `P*D/(D - dD)`.
2. **Ceiling.** Under the same hypotheses and `P ≤ Pmax`:
   `(∃ P', P' ≤ Pmax ∧ cap P' (D - dD) C = cap P D C) ↔ dD ≤ D * (1 - P/Pmax)`.
3. **Divergence.** For `0 < C, P, D` and every `M` there is `δ > 0` such that every `dD` with
   `D - δ < dD < D` has `M < P*D/(D - dD)`.
4. **Complete loss.** For `0 < C, P, D` and every `P'`: `cap P' 0 C = 0` and
   `cap P' 0 C < cap P D C`.

The historical theorem `no_finite_compensation` (`Non_Substitutability_Complete.lean`, SHA-256
`8b1194634…bee273`) proves, in its formal text, exactly the existence half of part 1: the finite
increase `P·ΔD/(D − ΔD)` brings the total to `P + P·ΔD/(D−ΔD) = P·D/(D−ΔD)`, which restores the
bound. Its prose ("no finite power increase can fully compensate") is false in the interior. The
three things the prose might have meant are parts 2–4, each now stated separately.

**This result is elementary.** It is algebra of a single rational function; it is a correction,
not a new theorem.

## Why this is the right target

- Part 1 states what the historical theorem actually proves, plus uniqueness, so the
  "compensating power" is a well-defined quantity that parts 2 and 3 can refer to.
- Part 2 is what really limits compensation in the interior: a finite ceiling on power. The
  algebra was checked as the specification asks: the compensating power is
  `P' = P·D/(D − dD)`; for `D − dD > 0` and `Pmax > 0`, `P' ≤ Pmax ⇔ P·D ≤ Pmax·(D − dD)
  ⇔ dD ≤ D − P·D/Pmax = D·(1 − P/Pmax)`. `Pmax > 0` follows from `0 < P ≤ Pmax`, so Lean's
  convention `x/0 = 0` never applies.
- Part 3 is the honest content of "no finite compensation": the cost is finite for each partial
  loss but unbounded as the loss approaches all of `D`. It is stated with an explicit `δ`
  rather than `Filter.Tendsto … atTop` so the statement is readable without filter vocabulary;
  the two are equivalent.
- Part 4 is the only place where compensation is impossible: at `D = 0`.

Parts 3 and 4 carry the hypothesis `0 < C` although the compensating power in part 3 does not
involve `C`; it is kept to match the specification and the shared setting.

## Controls (sanity checks in the module)

- Witness `P = D = C = 1`, `dD = 1/2` needs `P' = 2`, and `cap 2 (1/2) 1 = cap 1 1 1`
  (`norm_num` over ℝ). With denominators cleared, the same witness is checked by `decide` over
  ℤ, including uniqueness of `P' = 2` among `0..10`.
- `Pmax = 2`: the ceiling condition holds with equality, `1/2 = 1·(1 − 1/2)`.
  `Pmax = 3/2`: it fails, `1/2 > 1/3`, matching `2 > 3/2`. Checked over ℝ by `norm_num` and in
  cleared form `P·D ≤ Pmax·(D − dD)` over ℤ by `decide`.
- Complete loss: `cap 1000 0 1 = 0 < cap 1 1 1`.

`decide` does not evaluate real-number arithmetic, and on ℚ it gets stuck in the kernel (tried:
both ℚ checks failed to reduce). So the ℝ checks use `norm_num`, as other sealed modules do,
and the `decide` checks use the equivalent integer forms.

**Negative controls (both proved in the module):**

- *Dropping `P ≤ Pmax` makes part 2 false.* `P = D = C = 1`, `dD = 1/2`, `Pmax = −1`: the right
  side `1/2 ≤ 1·(1 − 1/(−1)) = 2` holds, but no `P' ≤ −1` satisfies `P'·(1/2) = 1`. (For
  `0 < Pmax < P` both sides are false, so the counterexample needs `Pmax ≤ 0`; the hypothesis
  `P ≤ Pmax` is what supplies `Pmax > 0`.)
- *Dropping `dD < D` makes part 2 false.* `P = D = C = Pmax = 1`, `dD = 2`: `P' = −1 ≤ 1` and
  `cap (−1) (−1) 1 = 1 = cap 1 1 1`, so the left side holds, but `2 ≤ 1·(1 − 1) = 0` fails.
  Note that `dD = D` alone is *not* a counterexample (both sides are false there); the failure
  needs `dD > D`, where a negative "power" compensates a negative "diversity".

## What the statement does not establish

- Nothing about whether any agent preserves biodiversity. A capacity upper bound does not say
  the bound is attained, that more capacity serves an agent's goal, that biodiversity is the
  only source of the relevant information, or that preservation is the best action once costs
  are counted.
- Nothing about the Intelligence Bound as a physical conjecture: `cap` is an algebraic model,
  and nothing here says it describes any physical system.
