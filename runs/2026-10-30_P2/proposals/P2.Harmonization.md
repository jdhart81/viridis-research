## Kernel decision it backs

The Harmonization kernel coordinates `N` local stewards toward a shared target `X` by
broadcasting one scalar price `lamStar` instead of `N` individual commands. Each steward plays
its best response `br lamStar i = b i − lamStar / a i`. The kernel relies on two facts:
1. The broadcast price is feasible, meaning the best responses add up to the target exactly
   (market clearing).
2. The outcome is the centralised optimum, meaning no feasible allocation has lower total
   dissipation `J` (strong duality, no gap).

Together they justify replacing central allocation with price broadcasting. The kernel's
runtime identifier and TypeScript source were not among this session's inputs, so code
conformance is not addressed.

## What the statement says

For every `N : ℕ`, all `a b : Fin N → ℝ`, `0 < N`, `∀ i, 0 < a i`, and every `X : ℝ`:
1. `∑ i, br a b (lamStar a b X) i = X` (this is `ght_market_clears`);
2. `∀ y, ∑ i, y i = X → J a b (xStar a b X) ≤ J a b y`
   (this is `ght_strong_duality_decentralized_eq_centralized`).

Both canon theorems have the same hypotheses `(hN, ha)`. The canon's argument order is
`(a b) (hN) (ha) (X) (y) (hy)`, and the restatement follows it.

## Hypotheses (complete list)

| Hypothesis | Role |
|---|---|
| `0 < N` | At least one agent. Needed: with `N = 0` the aggregate is the empty sum `0`, which misses `X = 1` (control 5). |
| `∀ i, 0 < a i` | Strictly convex local dissipation. Gives `∑ 1/a i > 0`, so `lamStar` is well-defined, and makes the first-order condition a global minimum. |
| `∑ i, y i = X` (part 2) | Only feasible competitors are compared. Needed: the infeasible ideal `y = b` beats `xStar` (control 4). |

No sign or range restriction is placed on `b` or `X`, as in the canon.

## Why this is the right target

- These are the two theorems the brief names, with the canon hypotheses and nothing more.
  `ght_equimarginal` and `ght_best_response_minimizes` are proof ingredients, not kernel outputs,
  and they are not included. The dynamics (`ght_primal_dual_lyapunov_convergence`) are deferred
  in the canon itself.
- Non-triviality: on the local probe run, none of 28 one-shot tactics closed `Statement`.
  Part 2 needs the equimarginal identity, a pointwise convexity inequality and a sum
  manipulation.

## Relation to the ladder

Fourth in the P2 order. It is independent of the Restoration and Afforestation modules. It
shares the "shadow price" structure with the canon's water-filling family, which is not yet
in P2.

## Sanity examples in the module (canon non-vacuity instance `N = 2`, `a = b = (1, 1)`, `X = 0`)

1. `lamStar = 1`.
2. `xStar = (0, 0)`. The constraint binds (`xStar 0 ≠ b 0`), and `J xStar = 1`.
3. The competitor `y = (1, −1)` is feasible and has `J y = 2 > 1`.
4. **Negative control:** the infeasible `y = b` has `J y = 0 < 1`, so the feasibility hypothesis is essential.
5. **Negative control:** the wrong price `lam = 0` does not clear (the aggregate is 2, not 0).
6. **Negative control:** with `N = 0` the aggregate best response is `0 ≠ 1 = X`, so `0 < N` is essential.

All checks use `norm_num` or `simp`. Over ℝ, `decide` does not apply.

## Feasibility note

This session checked privately that the statement is provable. A port of the canon argument
(equimarginal identity, then pointwise tangent inequality, then summation) closes it with
axioms `propext`, `Classical.choice` and `Quot.sound` only. This is not claimed as a proof of
the proposal.
