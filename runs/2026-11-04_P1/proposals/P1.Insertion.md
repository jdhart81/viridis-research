# Rationale: `P1.Insertion` (L2, single-pixel insertion)

**Status: proposal only. Nothing here claims a proof of `Statement`.**

## What the statement says

```
invariant B := (enclosed B : ℤ) - C8 B + euler B
Statement := ∀ B p, p ∉ B → invariant (insert p B) = invariant B
```

`C8`, `enclosed`, `G4`, `G8`, `IsEnclosed` are restated identically to the `P1.Bridge`
proposal, because proposals cannot import one another. The complement is taken in all of
`ℤ²`, and a 4-component is enclosed when it is finite.

`Pixel`, `corners`, `vertices`, `hEdges`, `vEdges` and `euler` are restated character for
character from the sealed module `ViridisStatements.P1.BitQuad` (checked with `diff`). The module
imports only `Mathlib`. **Change from the 2026-11-03 draft:** that draft imported
`ViridisStatements.P1.BitQuad`, and the verifier rejected it before probing because the
module's object file was not available in its proposal environment. If Justin prefers the
import once it resolves there, the restated block can be replaced by
`open ViridisStatements.P1.BitQuad` and nothing else changes.

## "Every configuration of the 3×3 neighbourhood"

The statement places **no hypothesis** on the neighbourhood of `p`. It does not require `p`
to be a simple point, it does not require that `p` touches `B`, and it does not exclude
merging several 8-components or closing or filling holes. So all 256 configurations of the 8
neighbours are covered, each in every global context. Splitting into cases by configuration
is a matter for the proof, not for the statement. The module checks representative non-local
cases by `decide` (box model):

- closing a hole: ring minus its top middle, then insert it back (`χ` goes from 1 to 0, enclosed from 0 to 1);
- merging two 8-components: the two columns of the ring joined by `(1,0)` (`C8` goes from 2 to 1, `χ` from 2 to 1);
- corner-only closing: the last pixel of the diamond (`χ` goes from 1 to 0, the centre becomes enclosed);
- filling a hole: the centre of the ring (enclosed goes from 1 to 0, `χ` from 0 to 1).

In each case `boxInvariant` is 0 before and after.

**All 256 configurations by `decide` (new in this draft).** A second test oracle (namespace
`Mask`) encodes a 7×7 box as a 49-bit natural number and computes `C8`, the enclosed
count and `V − E + F` with bit operations, which the kernel evaluates quickly. With the
inserted pixel `p` at the centre, two `decide` examples check every one of the 256
neighbourhood configurations `N`:

- `allConfigs 0 256`: `N` alone. The invariant is 0 for `N` and for `N ∪ {p}`, so all 512
  subsets of the 3×3 window satisfy the L3 identity and every insertion at the centre
  preserves `enclosed − C8 + χ`.
- `allConfigs ring5 256`: `N` inside the closed 16-pixel ring at Chebyshev distance 2.
  Now all barrier neighbours are already 8-connected outside the window, and every
  non-barrier run around `p` lies in a finite region. This is the opposite extreme of
  global context from the first check.

Together these two contexts give the two extreme answers to the non-local questions that
the proof must settle: whether neighbouring pieces are already connected, and whether the
regions around `p` are finite. The global argument still has to handle every intermediate
context. The bitmask model also reproduces the three controls. A mutation test
(scratch only, not in the module) replaced 8-adjacency by 4-adjacency in the model's `C8`.
Both exhaustive checks then failed, so the table depends on the (8,4) pairing.
Both `decide` checks together take under a minute of elaboration.

`code/bridge_check.py` (rewritten tonight, independent of Lean) also tests each of the 256
configurations in 41 random contexts (10,496 insertions), with 0 failures. This is evidence,
not proof.

The same semantic control lemmas as in `P1.Bridge` are proved here (`Controls` namespace):
ring, block, diamond and empty raster, for `C8` and `enclosed` themselves.

## Why this is the right rung

`Δχ` is local. By L1 only the four windows at the corners of `p` change, so
`4Δχ` is a function of the 3×3 neighbourhood. `ΔC8` and `Δenclosed` are not local: whether two
neighbouring barrier pieces are already connected, and whether a complement region is
finite, depend on the whole raster. L2 isolates that difficulty into one step that has to be
proved. The expected proof route: with `k` the number of distinct 8-components of `B` meeting
`N8(p)`, `ΔC8 = 1 − k`. Each run of non-barrier 4-neighbours of `p`, cut by barrier
neighbours along the 8-cycle around `p`, either joins a complement component that already
exists or is split off, and a Jordan-type argument on that 8-cycle balances
`Δenclosed − ΔC8 + Δχ = 0`. That argument is exactly the step that must not be taken from a picture.

## Relation to the ladder

L3 (2) follows from L2 by `Finset.induction_on`. L3 (2) also implies L2 directly, so the two
are equivalent given the base case (empty raster, invariant 0, which the module proves for
the semantic definitions). Sealing both lets the proving task target the inductive step on
its own.
